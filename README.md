# TypeTale

TypeTale is an offline Electron typing coach with fake login, multiple practice modes, typing analytics, weak-key detection, progress tracking, and a liquid-glass themed interface.

## Features

- Fake login system for demonstration
- Separate local progress for each email and password pair
- Forgot password message that displays an OTP notice
- Multiple typing practice modes
- Expanded random typing-test library
- Mixed programming syntax practice
- WPM, accuracy, consistency, rhythm, and fatigue feedback
- Weak key and weak word detection
- Progress timeline
- Paper, Midnight, and Glass themes
- Apple-inspired liquid-glass UI style

## Tech Stack

- HTML
- CSS
- JavaScript
- Electron
- LocalStorage

## How To Run

Install dependencies:

```bash
npm install
```

Start the app:

```bash
npm start
```

## Note

This app does not use real authentication. Login is only for demonstration, and progress is stored locally in the app using `localStorage`.
